# マイルストーン1: 峠の防衛線

## 現状と改善点

開始時は単色の盤面、丸いユニット、手動操作の両陣営のみで、勝敗後の再戦や音がありませんでした。初期配信物はJS 1,214,296バイト、CSS 1,626バイト、HTML 1,459バイトで、gzip換算の合計は約333KBでした。画像・音声ファイルは0バイトでした。

## 実装

- 4種類のユニットと3種類の地形を、コードから24pxの小さなテクスチャとして生成。元ゲーム由来の素材は使用していません。
- 地形、移動・攻撃範囲、HP、選択状態を読み分けられる戦場と、目的・部隊・操作を整理したUI。
- 移動の補間、攻撃時の踏み込み、被弾の点滅とダメージ表示、ターンの幕、勝敗画面。
- 決定的な敵AI。敵は近い味方へ進み、攻撃可能なら攻撃します。勝敗後は再戦できます。
- 音声ファイルを使わないWeb Audioの短いメロディと効果音。音声切り替えボタン付き。
- ビルド時の配信容量検査。Playwrightで戦闘開始から勝利・再戦まで操作し、デスクトップとモバイルのスクリーンショットを保存。

## 残る課題と次のマイルストーン

- 音を鳴らす仕組みとブラウザエラーは自動検証しましたが、聴感上の品質は自動判定できません。
- 敵AIは基本行動のみです。障害物を考慮した戦術や複数の難易度はありません。
- 騎士と星詠みは現状、見た目と名前が異なります。次は射程、守備、支援などの役割を分け、地形効果と戦闘予測UIを追加します。その後、マップを1つ増やし、短い導入とクリア後の流れを作ります。
- スマートフォンでは盤面全体を表示するため、ピクセルテクスチャを縮小しています。操作性を上げるには、画面幅別の整数倍率表示とパン操作を検討します。
